PIXELCRYPT: Visual Cryptography & Pixel Manipulation Report
AetherCrypt/PixelCrypt is a modern, high-fidelity visual cryptography workbench designed to perform real-time pixel manipulation. The application is built entirely client-side using HTML5 Canvas, Vanilla CSS (Glassmorphic Theme), and custom ES6 JavaScript, eliminating the need for server-side processing and guaranteeing 100% data privacy.
